## 四、关键技术沉淀 / 铁律

1. **OmniRoute 免费层 `auto`/`best-coding` 路由硬卡死**（挂起 35s 超时）→ 须 pin 具体模型（如 `groq/llama-3.3-70b-versatile`）。
2. **WorkBuddy `models.json` 改动不热重载** → 必须完全退出重启进程。
3. **Hermes 模型选择须显式 `--provider omniroute`**，否则带前缀 id 被原生 provider 抢注导致模型偷换。
4. **Agnes 国内站地址 `https://api.agnes-ai.cn/v1`**（非 apihub、非 .com）；401 先看网络层能否拿到服务端 JSON 错误，再判 key。
5. **OmniRoute `DATA_DIR` 必须无空格路径**；它是 Electron GUI，启动只能用户桌面双击。
6. **Gridea 浓缩版需用户手动点「同步」**才上线（handoff_flow 只生成 published:true 草稿）。
7. **测试须温和**：验证 API 单次低频，禁触发 429/503 限流；多 provider 验证改清单让用户逐个点。
8. **博客永久链接**用 `:name`（含日期）保证每日独立 URL，勿用 `:slug`（会撞车）。
