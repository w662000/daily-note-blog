# 技术点 · 微信小游戏类别细分 · A3 一页纸（A 计划第二轮：六顶思考帽 + RACI + 多 Agent）

> 来源：交接文档《微信小游戏类别细分 · A3 一页纸（A 计划第二轮：六顶思考帽 + RACI + 多 Agent）》（2026-08-14）

---

## 一、技术选型

本调查要解决：个人/小团队预算有限，进入微信小游戏赛道时该选哪个类别。

选型结论：
- **研究方法**：六顶思考帽 + RACI + 多 Agent 并行的 A 计划工作流。
- **数据来源**：T0 微信公开课/腾讯财报/游戏工委法规；T1 DataEye/QuestMobile/阿拉丁/财报；T2 媒体估算仅作参考。
- **变现路径**：阶段一纯 IAA（广告变现）起步，阶段二跑出量后注册公司+版号再转 IAP 混合变现。
- **首推类别**：消除/解谜（最稳）、二合 Merge+模拟经营（付费天花板最高）、模拟经营（内容杠杆最高）。

---

## 二、实施要点与关键技术

1. **六顶思考帽分工**：白帽查事实、绿帽出方案、黄帽看收益、黑帽排风险、蓝帽定夺汇总，避免单 agent 偏见。
2. **RACI 责任矩阵**：每个子 agent 角色明确，主 agent 负责汇总拍板。
3. **可信度分层**：所有数字必须标 T0/T1/T2，官方增速与第三方买量成本不能混用。
4. **阶段化变现**：个人不能做 IAP（需版号+企业主体），必须先 IAA 验证。
5. **红线管理**：棋牌/捕鱼/重度 SLG/MMO 直接排除，合规或买量任一卡死。

## 三、模块职责划分

| 模块 | 职责 | 输出 |
|---|---|---|
| 白帽事实员 | 收集大盘、品类增速、付费人群数据 | 数据底表 |
| 绿帽+黄帽规划员 | 产出推荐类别与切入路径 | 推荐清单 |
| 黑帽挑刺员 | 识别版号、iOS IAP、买量、合规风险 | 风险矩阵 |
| 蓝帽主 agent | 综合三帽结论，给出最终排序与 MVP 建议 | A3 一页纸 |

---

## 四、如何选型（方法论）

1. **先定约束**：个人/小团队、无大买量预算、混合变现。
2. **再定口径**：T0 官方、T1 权威第三方、T2 媒体估算，严格分层。
3. **多角色并行**：六顶思考帽把「调查、创意、收益、风险、决策」拆开，避免一团浆糊。
4. **阶段化落地**：先 IAA 跑量验证，再补版号转混合，不可颠倒。
5. **红线前置**：把「个人不能做 IAP」「iOS 无法收虚拟支付」作为硬约束先写入。
