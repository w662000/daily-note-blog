## 问题：视频生成 HTTP 404 错误

### 现象
- 第一个5秒视频成功生成
- 后续10秒、15秒视频全部返回 HTTP 404
- 错误信息：`litellm.NotFoundError: NotFoundError: OpenAIException - {"detail":"Not Found"}`

### 根因
Agnes Video Generator 默认配置使用 `apihub.agnes-ai.cn`，但实际API端点是 `api.agnes-ai.cn`（无hub）。

### 解决方案
修改 `core/config.py` 第482-484行：

```python
# 原配置（错误）
AGNES_DOMAIN_MAP = {
    "com": "https://apihub.agnes-ai.com",
    "cn": "https://apihub.agnes-ai.cn",
}

# 修正后（正确）
AGNES_DOMAIN_MAP = {
    "com": "https://api.agnes-ai.com",
    "cn": "https://api.agnes-ai.cn",
}
```

或通过API配置：
```bash
curl -X POST http://localhost:8765/api/config/domain -F "domain=cn"
```

### 注意事项
- API Key 格式为 `sk-` 开头
- 视频生成使用 Form 表单（`-F` 参数），不是 JSON（`-d` 参数）
- 国内站端点：`https://api.agnes-ai.cn/v1`
- 国际站端点：`https://api.agnes-ai.com/v1`

### 后续测试
- 5秒视频：✅ 成功
- 10秒视频：❌ 失败（可能是API Key权限不足）
- 15秒视频：❌ 失败（同上）

建议用户检查API Key是否有视频生成权限。
