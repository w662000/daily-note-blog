## 完成内容
### 1. 东财龙虎榜（支持历史日期）
```
https://datacenter-web.eastmoney.com/api/data/v1/get
  ?reportName=RPT_DAILYBILLBOARD_DETAILSNEW
  &columns=ALL&pageNumber=1&pageSize=500
  &sortColumns=BILLBOARD_NET_AMT&sortTypes=-1
  &filter=(TRADE_DATE='2026-07-24')     # 需 URL 编码
  &source=WEB&client=WEB
```
返回 `result.count=84` / 72 只去重个股。关键字段：
`SECURITY_CODE` `SECURITY_NAME_ABBR` `CHANGE_RATE` `CLOSE_PRICE` `TURNOVERRATE`
`BILLBOARD_NET_AMT`（净买入，元）`ACCUM_AMOUNT`（成交额）`EXPLANATION`（上榜原因）。
同一股票可因多个上榜原因出现多条明细，必须按代码去重后再求和，否则净买入翻倍。

### 2. 同花顺强势股题材归因（支持历史日期）
```
https://zx.10jqka.com.cn/event/api/getharden/?date=2026-07-24
```
返回 42 只，每只 `reason` 用「+」分隔（42/42 都含 +），另含 `zhangfu` `huanshou` `close` `chengjiaoe`。
注意：接口级 `date` 字段返回的是当天（2026-11-12），**个股记录里的 `date` 才是 2026-07-24**，已逐条核对一致。
不带 date 时返回的是当日强势股（37 只），不能用于历史复盘。

### 3. 东财行业板块
- 板块清单（实时全字段，批量）：
```
https://push2his.eastmoney.com/api/qt/ulist.np/get?fltt=2&invt=2
  &fields=f12,f14,f3,f104,f105,f128,f140,f141
  &secids=90.BK0447,90.BK1036,...      # 无效代码会被自动忽略
```
`f3` 涨跌幅、`f104` 上涨家数、`f105` 下跌家数、`f128` 领涨股、`f140` 领涨股代码。
实测 `date=20260724` / `date=2026-07-24` **均被忽略**（与不带参数返回完全一致）→ 无历史回溯能力。
本机 `push2.eastmoney.com` / `push2delay` / `82.push2` 的 `clist/get` 全部 RemoteDisconnected；
`http://127.0.0.1:8851/api/qt/clist/get` 本地代理可用但只回 f12/f14/f62 三字段（且 f12 被写成名称）。

- 板块历史日 K（支持历史，但限流）：
```
https://push2his.eastmoney.com/api/qt/stock/kline/get?klt=101&fqt=1
  &beg=20260724&end=20260724
  &fields1=f1,f2,f3&fields2=f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61
  &secid=90.BK0447
```
`klines[0]` 第 9 个字段（下标 8）= 涨跌幅。
- 板块历史资金流日线（备用通道，字段更多）：
```
https://push2his.eastmoney.com/api/qt/stock/fflow/daykline/get?lmt=0&klt=101
  &secid=90.BK0447
  &fields1=f1,f2,f3,f7&fields2=f51,...,f65
```
返回 120 天历史；7-24 行下标 1 = 主力净流入（元）、下标 11 = 板块指数收盘、下标 12 = 涨跌幅。
已用 BK0447 互联网服务做交叉校准：日 K `f59 = -3.63` 与资金流日线 `f63 = -3.63` 完全一致。
