# AutoClaw 模型添加方法纠错 + 完成（2026-08-18 23:39）

## 背景
用户反馈：b-ai 和 wechat 在 AutoClaw 都没加成功。我 23:26 直接改 `~/.openclaw-autoclaw/openclaw.json` 的 models.providers → 错误方法，UI 不显示。

## 根因（从 app.asar 源码核实）
**AutoClaw 模型管理机制**：
- `AppData\Roaming\autoclaw\settings.json` 的 `models.catalog` = **源**（UI 添加模型写这里）
- `~/.openclaw-autoclaw/openclaw.json` 的 `models.providers` = **产物**（sanitize 时从 catalog 推导生成）
- 只改 openclaw.json → catalog 没有条目 → UI 不显示
- 代码证据：
  - `index.js:116788-116887` sanitize 遍历 catalog 自定义条目 → 生成/更新 providers
  - `index.js:32135` assignCustomModelConfigIds 自动分配 configId
  - `index.js:31520` withSafeEncryptedSecrets 写盘自动加密明文 key
  - `index.js:742` getGatewayProviderKey = `provider__configId`

## 正确做法（已执行）
往 settings.json 的 models.catalog 追加（字段对齐现有 sensenova 条目）：
```json
{
  "provider": "wechat",
  "model": "Deepseek-v4-flash",
  "alias": "[WeChat] Deepseek-v4-flash (小程序大赛)",
  "apiKey": "<明文微信key>",
  "baseUrl": "https://chatapi.weixin.qq.com/openai/v1",
  "api": "openai-completions",
  "isCustom": true,
  "configId": "33f001d6-82ee-4864-bc94-41adca4f75d8",
  "reasoning": true
}
```
以及 b-ai 条目（configId=62b5c153-8656-4dd1-bd9b-a134e6b19222）。

- 写盘后 AutoClaw 运行中自动把明文 key 加密成 enc:（已核实非空）
