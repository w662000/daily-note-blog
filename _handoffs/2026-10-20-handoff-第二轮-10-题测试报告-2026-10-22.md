## 二、本轮最大发现：grounding 静默失效（P0）

**现象**：Q10 问 Cloudflare Workers AI 免费额度，答案说"每月 10 万次请求 + 10M token，超出 $0.50/M"——**全错**（实际是每天 10,000 neurons）。Q3 满嘴 2024 年旧型号也无人纠。

**定位过程**：
1. gquota 显示今天 grounding 被调 18 次（6 题×3 条）——跑了
2. 本地 mock DB 复跑同一条 claim → 返回空 → 链路或 key 问题
3. 本机代理直连 Gemini API → **429 RESOURCE_EXHAUSTED（配额耗尽）**；不带搜索工具再测 → **400 User location is not supported（账号地区不受支持）**
4. 结论：**这个 Gemini key 已不可用**（429 配额耗尽 + 400 地区限制双重问题）。grounding.js 原来把 `!res.ok` 静默吞掉返回 null，所以线上表现是"跑了 18 次、零产出"，用户无感知

**已修复（版本 2c914b5e）**：
- verifyOne 返回结构化结果，429/400 识别为 key 级致命错误
- 当天熔断：命中致命错误当天不再调用（gquota.broken=1），后续问题直接跳过，不再每题空跑 20s
- schema 加 broken 列（已远程 ALTER）

**待用户决策**：这个 key 需要处理——
- 选项 A：用户提供新的可用 Gemini key（`wrangler secret put GEMINI_API_KEY`）
- 选项 B：先接受 grounding 停用，靠 prompt 红线+六维审核兜底（效力降一档）
- 选项 C：换核查源（智谱 GLM-4-Flash 的 web_search 工具，models.json 里有现成 key）

## 五、核查源更换（选项 C）执行结果 — 2026-10-22 14:xx

**结论：原方案 C（智谱 GLM-4-Flash web_search）不可行，已改为 OpenRouter → perplexity/sonar，核查能力已恢复并验证。**

### 5.1 为什么智谱走不通（实测，不是推测）

| 测试 | 结果 |
|---|---|
| `glm-4-flash-250414` + web_search 工具 | 200，但**静默忽略工具**：带工具与不带工具输出一字不差，还编造"Cloudflare 官网 2024 年 5 月信息显示…" |
| `glm-4-flash` + function 工具 | ✅ tool_calls 正常 → **模型支持 tools，但不支持 web_search 类型** |
| 独立 `POST /web_search` | 429 `1113 余额不足或无可用资源包` |
| 付费模型 `glm-4.7` | 429 `1113 余额不足` → **账号零余额** |
| `glm-4.5-air` / `glm-4.7-flash` | 429 余额不足 / 访问量过大 |

智谱搜索是**计费**能力（search_std 0.01 元/次、search_pro 0.03 元/次），免费模型不支持。
更关键：带 web_search 时它会**伪造"属实 + 编造来源"**——比空返回更危险。

### 5.2 顺手排除的其它选项

- `models.json` 里的 Gemini key（53 字符）：**同样 429 配额耗尽** → 选项 A 无法靠现有 key 解决
- Bing / DuckDuckGo 抓取：CN 出口返回本地化营销页；代理出口返回"波士顿旅游景点""天空为什么是蓝的"——**200 但内容是垃圾**，静默失效
- OpenRouter `:online`（gpt-4o-mini 等）：403 地区限制；`gemini-2.0-flash:online`、`grok-4-fast:online` 已下线

### 5.3 最终方案：OpenRouter → `perplexity/sonar`

| 项 | 值 |
|---|---|
| 模型 | `perplexity/sonar`（自带联网，返回 `url_citation` 注解） |
| 密钥 | `OPENROUTER_API_KEY`（wrangler secret，用 models.json 里现成的 OpenRouter key） |
| 成本 | **$0.005/次搜索**（Perplexity 按次计费）+ 少量 token；3 条声明**合并成一次调用**，≈ 3.6 分钱/题 |
| 日限 | `GROUNDING_DAILY_CAP=100` |
| 熔断 | 401/402/429 → 当天 `gquota.broken=1`；**403 不熔断**（那是模型地区限制，熔断会把它伪装成 key 废了） |

**新增防伪规则（核心）**：裁决必须附带本次检索命中的真实 URL，**否则整批丢弃**。
实测无联网模型（llama-3.3-70b / gemma-3-27b）面对同一条说法都给出错误的"部分属实"并编造链接，
全部被这条规则拦下——这正是"假裁判比没裁判更糟"的结构性解法。

### 5.4 修复验证（Q10 同题复测，线上 4ea1fbd2）

### 5.7 再换源：Tavily（最终方案）— 2026-10-22 15:xx

**为什么又换**：用户追问"OpenRouter 没绑卡怎么付费"，查实后确认 sonar 方案不可持续。

```
GET /api/v1/credits → {"total_credits": 0, "total_usage": 0.0598}
```

- `total_credits=0`：**从未充值**，用量却在累计（余额为负）
- 能跑通的原因：OpenRouter 预扣只估算 **token 费用**，不含 `$0.005/次` 的搜索费；
  sonar 的 token 费约 $0.00006，预扣≈0 → 余额检查放行 → 结算时才记 $0.005
- 铁证：把 `max_tokens` 抬到 30000 立刻 402 —— `you can only afford 28037`（≈$0.028 预算），
  提示语是 "upgrade to a **paid account**"，说明免费档在吃自己的预算，不是有余额
- 结论：**漏洞式可用，随时会断**，且断了会以"402 → 熔断 → 核查零产出"重演 P0

**最终方案：Tavily Search（用户已有 key，免费 1000 次/月）**

| 项 | 值 |
|---|---|
| 额度 | `current_plan: Researcher`，`plan_limit: 1000`（实测 `/usage` 可查） |
| 返回 | `answer`（由检索结果生成的摘要）+ `results[]`（title/url/content/score） |
| 每题消耗 | 最多 2 次搜索（`GROUNDING_MAX_CLAIMS=2`） |
| 日限 | 30 次搜索（≈900/月，留 10% 余量） |

**关键架构调整：不再让任何模型出裁决。**
实测智谱 glm-4-flash 当裁判时，把 **Workers KV 的"每日 10 万次"错认成 Workers AI 的额度**，
判成"部分属实"——裁判自己幻觉，证据链就废了。改为：

- **Tavily 的 `answer`** 作为【检索事实】（它由自己的检索结果生成，不是模型记忆）
- **代码做确定性数字核对**：声明里的数字（`numbersIn`：10 万→100000、1,000→1000）是否出现在检索事实里
- 对不上 → 标 `mismatch` → 审核员与汇总都能看到 ⚠️，但**不假装判断语义真假**
- 来源链接只来自 `results[].url`，**任何模型都无法编造来源**

**验证（线上 1e656820）**

- 本地链路：1 条声明 → 1 次搜索 → 3 条真实来源；检索事实为 "10,000 neurons per day"，
  数字核对正确报出 `⚠️ 未出现`（声明是 100000/10000000）
- Q10 同题：答案改为 **每天 10,000 Neurons / $0.011 per 1,000 Neurons**，
  并明确写出"每月 100,000 次 + 10M Token 属未验证说法"
- 多轮追问：37,500 vs 300,000 算术全对，且把"250 Neurons"标注为**估算值**（证据驱动的降级生效）
- gquota 计数 2 次（= 2 次 Tavily 搜索），与 `GROUNDING_MAX_CLAIMS=2` 一致

**仍存在**：末轮审核仍可能挑出"草稿把 GPT-4/Claude 当成 Workers AI 模型"这类**真实**小瑕疵 →
横幅挂着。这是正常拦截，不是误报。

**注**：Tavily `/usage` 接口的 `plan_usage` 当前仍显示 0（疑似统计延迟），
额度以 `plan_limit=1000` 为准，本地 `gquota` 表是更实时的计数依据。
