## 二、关键决策 / 注意事项

- **GitHub 令牌已失效**：本机 `gh auth status` 报 token 无效，本地 git 推外网会失败。今天 GitHub 同步需待 `gh auth refresh` 后生效（复制与提交本身是本地操作，配好 gh 后下次即生效）。
- **58 反爬靠「真浏览器 + 新鲜 fzq_h」**：单凭带 Cookie 的 urllib 已无法过验证码网关；Playwright 必须「跨频道热身」才能生成 fzq_h，且不可冷启动直冲买房频道（会被主动验证码墙拦截）。
- **Playwright 实例只启一次**：每片区只重开**浏览器**，否则进程内事件循环冲突会报 `asyncio` 错误，导致后续片区全跳（今天租房全量就踩过这个坑，已修）。
- **换 IP 只换「短暂宽限」**：重启光猫换 IP 仅换来约 3–4 个买房区的抓取额度；真正稳的续命方式是**用户在自家浏览器手动点一次 58 验证**——共享同一住宅出口 IP，验证后连 headless 爬虫也一起被放行。
- **严禁浪费宽限额度做探针/门禁测试**：今天买房后 3 区就是因为反复 `--test` 把新 IP 额度耗光而全撞墙，教训深刻——拿到新 IP/新验证后应立即直奔目标区爬。
- **灌库去重**：D1 的 `price_records` 表无唯一约束，`INSERT OR IGNORE` 不防重复，灌全量前必须先 `DELETE` 叶子表再导入。
